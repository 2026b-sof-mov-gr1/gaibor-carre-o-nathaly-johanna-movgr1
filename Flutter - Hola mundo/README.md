# Hola Mundo - Flutter 

Mi primer proyecto desarrollado con **Flutter y Dart**, creado como parte de mi aprendizaje en el desarrollo de aplicaciones móviles.

## 📱 Descripción

Este proyecto consiste en una aplicación básica que permite dar los primeros pasos con Flutter, conocer su estructura y familiarizarse con el proceso de ejecución de una aplicación en un emulador Android.

## 🛠️ Tecnologías utilizadas

- **Flutter:** 3.47.8
- **Dart:** 3.13.7
- **Android Studio:** Entorno de desarrollo.
- **Git y GitHub:** Control de versiones y almacenamiento del código fuente.

##  Requisitos previos

Para ejecutar este proyecto necesitas:

- Flutter instalado y configurado.
- Dart SDK.
- Android Studio.
- Android SDK y un emulador Android.
- Git.

##  Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone URL_DE_TU_REPOSITORIO
   ```

2. Entrar en la carpeta del proyecto:

   ```bash
   cd hola_mundo
   ```

3. Instalar las dependencias:

   ```bash
   flutter pub get
   ```

4. Ejecutar la aplicación:

   ```bash
   flutter run
   ```

##  Estructura del proyecto

```text
hola_mundo/
├── android/       # Configuración para Android
├── ios/           # Configuración para iOS
├── lib/
│   └── main.dart  # Punto de entrada de la aplicación
├── test/          # Pruebas del proyecto
├── pubspec.yaml   # Dependencias y configuración
└── README.md      # Documentación
```

## Objetivo de aprendizaje

Familiarizarme con Flutter, comprender la estructura básica de un proyecto y realizar la primera ejecución de una aplicación móvil utilizando un emulador Android.
